# hxyfront-62007 植物标本馆入库

源提示词编号：9

开发一个植物标本馆压制标本入库前端项目，工作人员可以录入采集号、物种名称、采集地点、海拔、生境描述、采集人、压制状态、鉴定状态和馆藏位置。页面需要有入库队列、鉴定状态筛选、采集地点信息卡、馆藏柜位记录和单份标本详情页。

## 功能

- **标本录入**：采集号、物种名称、采集地点、海拔、生境描述、采集人、尺寸档位、压制状态、鉴定状态、鉴定结果，可直接分配柜位或先入入库队列
- **柜位推荐**：按"同地点 + 尺寸档位接近"优先同柜打分推荐；容量不足或无匹配时优先推荐空柜
- **占用冲突检测**：保存前重新校验柜位占用，若刚被其他标本占用，弹出冲突提示（展示占用标本及其放入时间），保留占用方原有分配，并给出可改用的柜位一键保存
- **入库队列**：按鉴定状态（待鉴定/已鉴定/需复核）与柜位筛选，支持采集号/物种/地点搜索
- **标本详情**：采集记录、鉴定信息更新、柜位分配/调整/移出，以及完整的柜位调整经过时间线
- **柜位看板**：各柜容量、占用进度与柜内标本清单
- **持久化**：全部数据保存于 localStorage，刷新或重开页面仍在；多标签页通过 storage 事件同步，可真实复现柜位冲突场景

## 技术栈

React + Vite + TypeScript
